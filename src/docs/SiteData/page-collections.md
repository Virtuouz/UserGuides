This is where you set up your tags and the default image for your custom page collections. To learn more about how to use page collections, check out the page collection "Getting Started."

## Default Image

This is where you set up your default image for your page collections. If a page you add to a page collection doesn't have an image, this image will be used instead.

![](/assets/images/uploads/image-112.png)

## Tags

This is where you set up the tags that you want to make available to choose from to create your page collections.
